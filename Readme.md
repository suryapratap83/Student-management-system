# 🎓 Student Management System in C

A console-based Student Management System built in C.
This is my first BCA project built completely from scratch!

---

## 📌 About

This project helps manage student records through a
simple console interface. It supports adding, viewing,
searching, updating and deleting student records with
permanent data storage using binary file handling.

## ✨ Features

- 🔐 Login system with 3 attempts
- ➕ Add new student
- 👁️ View all students
- 🔍 Search student by roll number
- ✏️ Update student details
- 🗑️ Delete student
- 💾 Permanent data storage using binary file handling
- 📁 Data saved in students.dat automatically

---

## 🧠 Concepts Covered

- Structs
- Arrays
- Functions
- Loops and switch cases
- File handling (fread, fwrite)
- String comparison (strcmp)
- Binary files (.dat)
- do-while loop
- Linear search
- Array shifting for delete
